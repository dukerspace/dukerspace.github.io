This is the first post on dukerspace.com.

Posts live as `.md` files. The site reads them into an index and an article page. A new post is a file in `content/blog/en`, with the Thai version beside it in `content/blog/th`.

I will write about work in progress, tools I use, and short lessons from personal projects.
