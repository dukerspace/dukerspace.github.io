เมื่อใช้ AI coding agent ข้อมูลทุกอย่างที่ส่งให้เอเจนต์มีต้นทุน ทั้งพรอมต์ ผลลัพธ์จากคำสั่งเชลล์ และเนื้อหาไฟล์ที่อ่านเข้ามา Rimping จึงโฟกัสที่การลดโทเคนจากข้อมูลเหล่านี้ก่อนจะไปถึงเอเจนต์ โดยไม่เปลี่ยนโจทย์หลักของงาน

## ลดข้อมูลจากสามจุด

Rimping ทำงานกับข้อมูลสามประเภทที่พบเป็นประจำใน workflow การเขียนโค้ด:

- **พรอมต์:** ตัดคำฟุ่มเฟือยและจัดการ diff ก่อนส่ง
- **ผลลัพธ์เชลล์:** ลดส่วนเกินจาก output ของคำสั่ง
- **การอ่านไฟล์:** ช่วยลดข้อมูลที่ต้องส่งต่อจากไฟล์

เหตุผลที่แยกเป็นสามจุดคือข้อมูลแต่ละแบบมีบริบทไม่เหมือนกัน พรอมต์มีคำสั่งและข้อกำหนด ผลลัพธ์เชลล์อาจมีรายละเอียดที่ไม่เกี่ยวกับคำถาม ส่วนไฟล์อาจมีเนื้อหามากกว่าส่วนที่ต้องใช้ การลดข้อมูลจึงไม่ควรหมายถึงตัดทุกอย่างให้สั้นที่สุด แต่ควรลดส่วนเกินโดยยังรักษาสิ่งที่เอเจนต์ต้องใช้ทำงาน

การจัดการหลายจุดใน workflow เดียวช่วยลดการแก้ข้อความหรือคัดลอกผลลัพธ์ด้วยมือ และทำให้คิดเรื่องต้นทุนบริบทได้ตั้งแต่ก่อนข้อมูลเข้าสู่เอเจนต์ แทนที่จะค่อยแก้เมื่อพรอมต์ยาวเกินไป

## Dstack สำหรับบริบทของเอเจนต์

อีกส่วนหนึ่งของโปรเจกต์คือ Dstack ซึ่งเป็นชุดไฟล์สำหรับจัดระเบียบ workflow ของเอเจนต์ มีทั้ง `AGENTS.md`, งบประมาณโทเคน, สกิล และอะแดปเตอร์ ส่วนนี้ช่วยวางแนวทางและบริบทให้เอเจนต์ทำงานได้กระชับขึ้น

Rimping ยังมีฮุกสำหรับ Cursor, Claude Code และ Codex เพื่อเชื่อมการทำงานเข้ากับเครื่องมือที่รองรับ โดยตัวโปรเจกต์เขียนด้วย TypeScript และใช้ Bun

## แยกการจัดการข้อมูลออกจากแนวทาง

การลดข้อมูลที่ส่งเข้าเอเจนต์เป็นเรื่องของการจัดการข้อมูลระหว่างทาง ส่วนการให้แนวทางกับเอเจนต์เป็นเรื่องของการจัดระเบียบบริบท Rimping จึงวางทั้งสองอย่างไว้ด้วยกัน แต่แยกบทบาทให้เห็นชัด: ตัวเครื่องมือช่วยจัดการข้อมูล ส่วน Dstack ช่วยจัดระเบียบไฟล์และ workflow

การแยกหน้าที่แบบนี้ช่วยให้เห็นว่าปัญหาไม่ได้มีแค่จำนวนโทเคน แต่ยังรวมถึงการส่งบริบทที่เหมาะสมไปด้วย ถ้าบีบข้อมูลอย่างเดียวแต่ไม่มีแนวทางหรือข้อกำหนดที่ชัดเจน เอเจนต์ก็ยังอาจทำงานได้ไม่ตรงเป้าหมาย

## สิ่งที่ได้เรียนรู้

เมื่อสร้างเครื่องมือสำหรับ AI workflow การประหยัดโทเคนเป็นเพียงส่วนหนึ่งของโจทย์ ความชัดเจนของคำสั่ง คุณภาพของบริบท และการเชื่อมกับเครื่องมือที่ใช้อยู่ก็สำคัญด้วย Rimping จึงมองการลดข้อมูลและการจัดระเบียบไฟล์เป็นงานที่เสริมกัน ไม่ใช่สิ่งเดียวกัน
