Suthep

เครื่องมือดีพลอย Docker พร้อม Nginx reverse proxy และ HTTPS อัตโนมัติ

เกี่ยวกับ

Suthep เป็นเครื่องมือ CLI สำหรับดีพลอยโปรเจกต์ พร้อมตั้งค่า Nginx reverse proxy, HTTPS ด้วย Certbot และการดีพลอยแบบ zero-downtime ออกแบบมาสำหรับโปรเจกต์งบน้อย ช่วยให้ดีพลอย Docker ได้ง่ายด้วยการตั้งค่าน้อย

ฟีเจอร์หลัก

  • ตั้งค่า Nginx reverse proxy อัตโนมัติ - ตั้งค่า Nginx ให้บริการของคุณโดยอัตโนมัติ
  • HTTPS อัตโนมัติด้วย Certbot - ตั้งค่าใบรับรอง SSL จาก Let's Encrypt
  • ดีพลอยแบบ zero-downtime - อัปเดตได้อย่างราบรื่นโดยไม่ขัดจังหวะบริการ
  • รองรับ Docker container - ดีพลอยและจัดการ Docker container ได้ง่าย
  • รองรับหลายโดเมน/ซับโดเมน - ตั้งค่าหลายโดเมนสำหรับบริการของคุณ
  • ตรวจสอบสุขภาพบริการ - มอนิเตอร์สุขภาพบริการโดยอัตโนมัติ
  • ตั้งค่าด้วย YAML - ไฟล์คอนฟิกแบบประกาศ เรียบง่าย

เทคโนโลยี

สร้างด้วย TypeScript รองรับการดีพลอยบน Docker ผสานกับ Nginx และ Certbot สำหรับการดีพลอยพร้อมใช้งานจริงพร้อมจัดการใบรับรอง SSL อัตโนมัติ
